# AI Image Text & Font Editor Pro

Modern browser-based image text editor with OCR, auto font matching, and live editing.

## Features
- OCR (English + Hindi) via Tesseract.js
- Auto font size, color & family detection
- Live preview while editing
- Smart erase / inpaint
- Undo support
- Add new text anywhere

## Local
```bash
npm install
npm run dev
```
